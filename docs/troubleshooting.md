# 故障排查

## Chromium 下载或启动失败

首次运行可能需要下载 Remotion 管理的 Chromium。确认网络允许访问下载源、磁盘有可用空间；重新执行命令即可。不要把浏览器路径写进输入包。

## macOS 版本提示

Remotion 在 macOS 15 以下会打印功能提示。本项目渲染时使用锁定在 `node_modules` 内的兼容 FFmpeg/FFprobe，不依赖系统全局二进制；提示本身不表示失败。若 Chromium 本身无法启动，请升级系统或改在兼容机器运行。

## 端口冲突

每个 Studio 实例使用独立端口，例如 3101、3102。端口已占用会以退出码 5 结束，换一个未占用端口重试。

## 输出目录或锁冲突

输出目录必须不存在或为空。正常退出会释放同级 `.输出目录名.video-renderer.lock`。若进程被强制终止，下次任务会检查锁中 PID：确认本机进程已死亡才自动回收；活进程、外部主机或无法解析的锁不会被抢占。不要在渲染过程中手工删除锁。

## 资源压力

任务级并行与帧级并发会叠加。出现内存不足、系统卡顿或 Chromium 崩溃时，把每个任务的 `--concurrency` 降为 1，并减少同时运行的任务数量。

## 时间线校验失败

检查首镜头是否从 0 开始、镜头是否连续、末镜头与旁白是否在 100ms 容差内、字幕是否重叠，以及 crossfade 是否短于出镜头且不长于入镜头。

## 成片技术校验失败

退出码 7 表示渲染已结束但成片不满足 H.264、1080×1920、正时长或非空文件等条件。保留 stderr 诊断，确认项目依赖未被替换，再执行 `npm ci` 后重试。
